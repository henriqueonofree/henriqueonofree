# ⚙️ Detection Engineering

Uma área que considero fundamental dentro de um SOC é transformar **investigações reais em melhorias de detecção**.

```text
Incidente
    ↓
Investigação
    ↓
Identificação da TTP
    ↓
Criação / ajuste da regra
    ↓
Teste
    ↓
Redução de falsos positivos
    ↓
Monitoramento
    ↓
Melhoria contínua
```

Interesses:

* SIEM Rules
* Wazuh Rules
* Detection Logic
* Log Correlation
* Alert Tuning
* MITRE ATT&CK Mapping
* IOC Detection
* Behavioral Detection
